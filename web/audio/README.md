# Sound effects

C64-style (SID chip) sound effects, generated by `make sfx` (`scripts/make-sfx.mjs`). Each one uses at most three SID voices, the SID waveforms (triangle, sawtooth, pulse, noise), ADSR envelopes, ring modulation and the resonant filter. All parameters change on 50 Hz PAL frames, like a real C64 sound driver. Output is 44.1 kHz 16-bit mono WAV. Don't edit the WAV files by hand; change the script and regenerate.

The game plays them through `web/sound.js` once the player turns sound on (the Sound button or **M**); `ntba_core::game::Cue` lists the in-game events.

| File | Intended for |
| --- | --- |
| `whistle_start.wav` | Tip-off: two referee blasts ("tweet, tweeeet") |
| `whistle.wav` | Single blast: violation, out of bounds, stoppage |
| `buzzer_final.wav` | End of game horn |
| `buzzer_shotclock.wav` | Shot-clock violation horn (shorter, higher) |
| `score_2.wav` | Two-point basket jingle |
| `score_3.wav` | Three-point basket fanfare |
| `swish.wav` | Ball through the net (layer under a score jingle) |
| `shot.wav` | Shot released |
| `pass.wav` | Pass thrown |
| `catch.wav` | Pass received |
| `rebound.wav` | Loose ball / rebound grabbed |
| `dribble_1.wav`, `dribble_2.wav` | Dribble bounce (alternate them so it isn't monotonous) |
| `steal.wav` | Steal |
| `block.wav` | Blocked shot |
| `miss.wav` | Rim clang on a miss (hit, then a second rattle) |
| `jump.wav` | Defensive jump |
| `tick.wav` | Countdown beep (last seconds of the game or shot clock) |
| `crowd_cheer.wav` | Crowd roar after a big play or at the final horn |
| `jingle_win.wav` | Game won |
| `jingle_lose.wav` | Game lost ("wah wah wah waaah") |
| `ui_move.wav` | Menu cursor move |
| `ui_select.wav` | Menu confirm |
| `ui_back.wav` | Menu back / cancel |
| `ui_notify.wav` | Lobby chat message or incoming challenge |
