# Get involved

NtBA is built in the open and we want you in it. You don't need to write code.

## Share an idea

Every idea belongs in the [issue tracker](https://github.com/EyalRo/NtBA/issues/new/choose) —
choose the **Idea** template. If it isn't written down, it gets lost, so please log it even if it's
half-formed. Look through the [existing ideas](https://github.com/EyalRo/NtBA/issues?q=is%3Aissue+label%3Aidea)
first and add a 👍 or a comment if someone had it before you.

## Find something to work on

- Issues tagged [`good first issue`](https://github.com/EyalRo/NtBA/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
  are small and well scoped.
- Issues tagged [`help wanted`](https://github.com/EyalRo/NtBA/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22)
  are bigger and we'd love a hand.
- Comment on the issue to say you're taking it, so two people don't build the same thing.

## Ways to help

| You are… | You could… |
| --- | --- |
| A player | Play the game, report bugs and things that feel off |
| A pixel artist | Draw sprite sheets (see the [Developer Guide](Developer-Guide#art)) — original art only |
| A musician / sound designer | Make original sound effects and music, including the 1984-style chip sounds |
| A programmer | Pick an issue; start with the [Developer Guide](Developer-Guide) and [Architecture](Architecture) |
| A basketball fan | Tell us what the rules and feel should be — see [Reference Games](Reference-Games) |
| A writer | Improve this wiki |

## Ground rule

Everything we ship is original. Never submit art, sound or code copied from commercial games.
