# Contributing to NtBA

Thanks for helping! NtBA is GPL-3.0-or-later; by contributing you agree your work is released
under that license. Everything must be original or compatibly licensed — **no assets copied from
commercial games**.

- **Got an idea?** [Open an issue](https://github.com/EyalRo/NtBA/issues/new/choose) with the *Idea* template.
- **Want to help?** See [Get Involved](https://github.com/EyalRo/NtBA/wiki/Get-Involved) on the wiki.
- **Writing code?** Read the [Developer Guide](https://github.com/EyalRo/NtBA/wiki/Developer-Guide).
  In short: `make check` must pass, game logic goes in `crates/ntba-core` with tests, and keep
  pull requests small and focused.
